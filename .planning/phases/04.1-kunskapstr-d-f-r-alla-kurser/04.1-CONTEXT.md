# Phase 04.1: Kunskapsträd för alla kurser - Context

**Gathered:** 2026-04-11 (assumptions mode)
**Status:** Ready for planning

<domain>
## Phase Boundary

Expand the kunskapsträd page (trad.astro) from Kurs B only to support all three courses (B, C, D) with course-appropriate visual tree sizes. C and D trees are visually bigger/more elaborate as a metaphor for CEFR level progression (B=A1 sapling, C=A2 medium tree, D=B1 full tree). The tree page shares localStorage state with the main checklist.

</domain>

<decisions>
## Implementation Decisions

### Course Switching
- **D-01:** Client-side tab switching on a single page, consistent with index.astro's pattern. Reuse the TabNav component's color scheme (cyan/violet/rose for B/C/D). All three course tree sets rendered in HTML, toggled via JS.
- **D-02:** Default to Kurs B tab (same as main checklist). Tab state is NOT persisted — students choose their course each visit.

### localStorage State Sharing
- **D-03:** Share localStorage state with the main checklist using existing key format `sfi-checklist-{course}` (e.g., `sfi-checklist-B`, `sfi-checklist-C`, `sfi-checklist-D`). Checking a leaf on the tree page reflects on the checklist and vice versa.
- **D-04:** Goal IDs are course-prefixed (B-HORA-01, C-HORA-01, etc.) so there is no collision between courses.

### Visual Tree Differentiation (CEFR Progression Metaphor)
- **D-05:** Tree artwork scales as a visual metaphor for CEFR level progression:
  - **Kurs B (A1):** Sapling — thinner trunk, smaller crown radius, simpler root system, tighter leaf arc
  - **Kurs C (A2):** Medium tree — standard trunk, moderate crown, developed roots
  - **Kurs D (B1):** Full mature tree — thick trunk, large lush crown, extensive root network, wider leaf spread
- **D-06:** Visual differentiation is achieved through SVG parameters (trunk width, crown radius, root complexity, leaf arc spread, viewBox dimensions) — NOT through goal count differences (which are nearly identical: B=34, C=34, D=32).
- **D-07:** Each course retains the same 6 skill groups (Höra, Läsa, Tala, Skriva, Uttal, Grammatik) with the same domain colors from design-tokens.

### Radar Chart
- **D-08:** One radar chart per course (shown within the active course tab). NOT an aggregate across courses.
- **D-09:** Radar chart structure remains identical — 6-axis hexagonal chart showing percentage completion per skill domain.

### Claude's Discretion
- Exact SVG dimensions and parameter values for each tree tier (sapling/medium/full)
- Whether to refactor tree rendering into a reusable Astro component or keep inline
- Branch path curvature and root detail differences between tiers
- Leaf node sizing per tier (could scale with tree size)
- Crown glow intensity scaling
- Whether tab navigation uses the existing TabNav component or a tree-page-specific variant

</decisions>
