# Phase 04.1 Plan 01: Multi-Course Tree Page — Frontmatter + HTML Template Summary

**One-liner:** Refactored trad.astro to import all three course JSON files, build tier-differentiated SVG tree data (sapling/medium/full), and render three tab-switched course panels with fully course-scoped SVG IDs.

## What Was Built

**Task 1 — Frontmatter refactor:**
- Added imports for `kurs-c.json` and `kurs-d.json` alongside existing `kurs-b.json`
- Defined `TIERS` constant with three tiers (sapling/medium/full) controlling trunk width, crown size, root count, leaf radius, and orbit radii
- Added `COURSE_TIER` mapping: B→sapling, C→medium, D→full
- Replaced hardcoded `skills` array with `buildSkills(kursData)` function
- Parameterized `computePositions(n, tier)` to use tier-specific arc/orbit values
- Built `allTreesData`, `allSkillsClient`, `allGoalTexts` for all three courses in a loop
- Updated `define:vars` from `{ skillsClient, goalTexts }` to `{ allSkillsClient, allGoalTexts }`

**Task 2 — HTML template:**
- Updated page title to `Kunskapsträdet` (course shown dynamically via `id="tree-header-subtitle"`)
- Added tab nav with `tree-tab` class (not `course-tab`) and `aria-controls` pointing to course panels
- Rendered three `course-tree-panel` divs: `tree-panel-B`, `tree-panel-C`, `tree-panel-D`
- Each panel has its own radar chart with course-scoped IDs (`radar-polygon-B`, `radar-dot-hora-B`, `pct-hora-B`)
- Trees grid uses course-scoped gradient IDs (`crown-B-hora`), progress attributes (`B-hora`), goal panel attributes (`B-hora`), and `data-course` on leaf nodes
- Tier-parameterized trunk path, crown ellipse, root paths, and leaf radius in each SVG
- Updated CSS `#radar-polygon` to attribute prefix selector `[id^="radar-polygon"]`
