    `import { Ear, BookOpen, MessageCircle, Mic, PenLine } from '@lucide/astro';`
    `const iconMap = { Ear, BookOpen, MessageCircle, Mic, PenLine };`
    `const IconComponent = iconMap[icon];`
    Render: `{IconComponent && <IconComponent size={24} class="text-white" />}` (per D-11: 24px min)
  - Label text: `<h2 class="text-white font-semibold text-lg">{label}</h2>` (per D-10: white on colored bg)
- Progress count line: Below header, a `<p class="text-sm text-gray-500 px-4 py-1" data-progress="{course}-{domainKey}">0 av {goals.length} avklarade</p>` (per D-13). JS updates this. Initial value is "0 av N avklarade".
- Goal list: `<div class="bg-white rounded-b-lg border border-t-0 border-gray-200 divide-y divide-gray-100">` containing GoalCheckbox for each goal.
- Wrap the whole section in a `<section class="mb-6">` for spacing.
