Create `UPPDATERA-KURSMAL.md` in the repo root. Written entirely in Swedish (per D-05). Target audience: a teacher with basic computer skills, not a developer (per D-04).

The guide must contain these sections (per D-06):

**1. Title and introduction**
- Title: `# Uppdatera kursmal`
- Brief intro explaining what this guide is for: when Skolverket updates the curriculum, the teacher can update the course goals on the website without any programming.

**2. Which files to edit**
- `src/data/kurs-b.json` -- Kurs B (CEFR A1)
- `src/data/kurs-c.json` -- Kurs C (CEFR A2)  
- `src/data/kurs-d.json` -- Kurs D (CEFR B1)
- Explain that each file contains all goals for one course.

**3. Step-by-step: How to edit on GitHub**
Numbered steps:
1. Go to `github.com/Plainmaster/sfi-kursmal`
2. Navigate to `src` > `data` folder
3. Click on the file to edit (e.g., `kurs-b.json`)
4. Click the pencil icon (edit) in the upper right
5. Find the goal text you want to change -- it is in the `"mal"` field inside quotes
6. Edit the text between the quotes
7. Click "Commit changes..." button
8. Write a short description (e.g., "Uppdaterade mal for horforstaelse kurs B")
9. Click "Commit changes"
10. Wait 1-2 minutes, then visit the site URL to see the changes

**4. What you CAN change**
- `"mal"`: The goal text the student sees (the "Jag kan..." sentences)
- `"teman"`: The theme tags (list from: relationer, miljo, bostad, arbete, fritid, hogtider, samhalle)

**5. What you must NOT change**
- `"id"` fields (e.g., `"B-HOR-01"`) -- these connect to saved student progress. Changing them resets student checkboxes.
- `"kurs"`, `"kursplan_year"`, `"cefr_niva"` -- course metadata
- `"domaner"` structure, `"namn"`, domain `"id"` -- the five skill domains are fixed
- Do NOT delete commas, brackets, or quotes

**6. Common mistakes and how to avoid them**
- Missing comma between items: every goal object must have a comma after it except the last one
- Unclosed quotes: make sure every `"` has a matching `"`
- If the site does not update after 5 minutes, check: did you save (commit) the change? Is there a JSON syntax error? (Netlify sends an email if the build fails)

**7. Example edit**
Show a before/after of changing one goal's `"mal"` text, with the surrounding JSON context so the teacher can see exactly what to change and what to leave alone.

Use the actual Netlify URL from Plan 01 if available in the SUMMARY, otherwise use `[SAJT-URL]` as a placeholder the executor will fill in.

Commit the file: `docs(deploy): add Swedish teacher guide for updating course goals`
Push to origin main: `git push origin main`
