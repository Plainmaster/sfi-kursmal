**3. Add print preparation JS to `src/pages/index.astro`** (per D-14, D-15):

Add a `beforeprint` / `afterprint` handler in the script block, after the initialization section. This handles the tricky part: showing the correct course panel + Min plan together during print.

```javascript
// --- 9. Print Preparation ---
let prePrintState = null;

window.addEventListener('beforeprint', () => {
  // Save current panel visibility state
  prePrintState = [];
  document.querySelectorAll('.course-panel').forEach(p => {
    prePrintState.push({ id: p.id, hidden: p.classList.contains('hidden') });
  });

  // Show the last-active course panel (D-14)
  document.querySelectorAll('.course-panel').forEach(p => {
    if (p.id === `panel-${lastActiveCourse}` || p.id === 'panel-plan') {
      p.classList.remove('hidden');
    } else {
      p.classList.add('hidden');
    }
  });

  // Update print header with active course (D-16)
  const printCourse = document.getElementById('print-course');
  if (printCourse) printCourse.textContent = lastActiveCourse;
});

window.addEventListener('afterprint', () => {
  // Restore panel visibility
  if (prePrintState) {
    prePrintState.forEach(({ id, hidden }) => {
      const p = document.getElementById(id);
      if (p) p.classList.toggle('hidden', hidden);
    });
    prePrintState = null;
  }
});
```

This ensures:
- Print always shows one course (the last viewed one, defaulting to B) plus Min plan
- After printing, the UI returns to whatever state it was in
- If user is on Min plan tab and prints, they see last course + Min plan (per Research pitfall 5)
- The print header shows the correct course letter
